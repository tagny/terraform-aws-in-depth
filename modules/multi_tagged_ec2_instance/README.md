## Example

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}

variable "region" {
  type        = string
  default     = "us-east-1"
  description = "The AWS Region to connect and run the tests in."
}

provider "aws" {
  region = var.region
}
data "aws_vpc" "default" {
  default = true
}

data "aws_subnets" "default" {
  filter {
    name   = "vpc-id"
    values = [data.aws_vpc.default.id]
  }
}

module "test_instance" {
  source         = "../"
  name_prefix    = "test_instance"
  tags           = { "author" : "Terraform AWS in depth" }
  instance_count = 5
  subnet_id      = data.aws_subnets.default.ids[0]
}

output "aws_instance_arns" {
  value = module.test_instance.aws_instance_arns
}
```

## Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| <a name="input_instance_count"></a> [instance\_count](#input\_instance\_count) | The number of instances to launch. | `number` | `0` | no |
| <a name="input_instance_type"></a> [instance\_type](#input\_instance\_type) | The type of the instance to launch | `string` | `"t3.micro"` | no |
| <a name="input_name_prefix"></a> [name\_prefix](#input\_name\_prefix) | The prefix to apply to the beginning of names generated by this module. | `string` | n/a | yes |
| <a name="input_subnet_id"></a> [subnet\_id](#input\_subnet\_id) | The ID of the Subnet to launch the instance into. | `string` | n/a | yes |
| <a name="input_tags"></a> [tags](#input\_tags) | Key/Value pairs to pass to AWS as Tags. | `map(string)` | `{}` | no |

## Outputs

| Name | Description |
| ---- | ----------- |
| <a name="output_aws_instance_arns"></a> [aws\_instance\_arns](#output\_aws\_instance\_arns) | The AWS Resource Name for the instances. |
| <a name="output_aws_instance_ips"></a> [aws\_instance\_ips](#output\_aws\_instance\_ips) | The IP Address for the private network interface on the instances. |
| <a name="output_aws_instances"></a> [aws\_instances](#output\_aws\_instances) | The entire instance resources. |
